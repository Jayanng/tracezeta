# TraceZeta — Full Codebase Audit (merged two-pass report)
Date: 2026-10-11. Pass 1: Hermes mechanical + judgment sweep. Pass 2: independent
Antigravity read-only review (did not see pass 1). Every citation below was
grep/read-verified against the tree before inclusion. READ-ONLY: no code changed.

## VERDICT
The core evidence machinery is genuinely real — the gate re-runs live probes,
the Investigator rejects unsupported hypotheses, the memory layer queries live
services — but five HIGH defects undercut the story: the sandbox can read the
API keys, the Verifier's span-diffing silently degenerates to a single boolean,
the Fixer invents fallback values (violating the project's own no-fabrication
rule), the source-repair flow is never invoked by the autonomous loop the
README diagrams, and the repo has no test suite.

## HIGH findings (confirmed)

H1. [shared] src/agents/verifier.js:88-89 — afterSpans always empty.
    Claim: span-level before/after red-teaming. Truth: runTask()
    (src/target/index.js:173-181) returns {ok, results, traceId, traceError,
    runFile, durationMs} — no `spans` field. `after.spans || []` is always [],
    so nowPassing/stillFailing/regressed are all trivially empty, `dropped`
    flags EVERY healthy step (visible in verifications/*.json), and acceptance
    degenerates to `after.ok === true`. The after run's spans ARE in the run
    record (run.spans) — the verifier reads the wrong field.
    Fix: load spans from after.runFile's record.

H2. [shared] src/agents/sandbox.js:30-39, 72-74 — protected set stale/incomplete;
    secrets exposed to the repair agent.
    PROTECTED_SET lists src/agents/source-repair.js (does not exist) and omits
    gate.js, classifier.js, source-flow.js — so the repair session can READ the
    anti-reward-hacking gate. Worse: `setfacl -R -m u:tracezeta-fix:rX ROOT`
    grants read on .env (NEATLOGS_WRITE_KEY, CRUSTDATA_API_KEY) and .git.
    The boundary probe earlier tested only the 7 then-existing protected files;
    gate/classifier/source-flow were never blocked and .env was never tested.
    Fix: PROTECTED_SET += gate.js, classifier.js, source-flow.js, .env, .git
    (or exclude .env/.git from the recursive grant), delete the stale entry.

H3. [shared] src/agents/fixer.js:149, 155 — Fixer INVENTS values.
    `valid = '2026-10-11';` when the date cannot be parsed; `parseInt(args.days)
    || 14` invents 14 days. Both violate "Fixer never invents values" — the
    established honest path is `remove: true`. The date literal is also stale
    tomorrow.
    Fix: un-derivable value -> flag the step `remove: true`, never substitute.

H4. [shared, unique scope] src/agents/source-flow.js never called by the loop.
    grep: zero call sites outside source-flow.js. orchestrator.js:84-88
    escalates when the Fixer refuses. README:22-26 diagram implies the loop
    does "a sandboxed patch to the source code itself". The Medic cycle is a
    separate manually-invoked entrypoint.
    Fix (pick one): wire attemptSourceRepair into the orchestrator's refusal
    branch, or reword the README to scope the source patch to the Medic cycle.

H5. [shared] No tests, no CI. package.json has no test script; no test/ dir;
    no workflows. The demo script is the only integration check.
    Fix: minimal node:test smoke suite over classifier/fixer/verifier pure
    logic + one recorded-fixture loop run.
